# Design and Analysis of Algorithms — Lab

Repository structure for the DAA laboratory exercises from the provided lab exercise PDF.

## Topics

1. Introduction
2. Brute Force
3. Divide and Conquer
4. Dynamic Programming
5. Greedy
6. Backtracking
7. Tractability and Approximation Algorithm

## Implementation policy

The experiment folders are intentionally scaffolded without source-code implementations.
Each experiment contains a README describing what should be implemented and a placeholder
for the eventual source file.

## Languages

Use the language required by the course/lab. Source-code files are placeholders only in this scaffold.
